This repository contains components developed as part of **Work Package 1 (WP1)** of the SustainML project.

WP1 focuses on **interpreting the machine learning problem definition** provided by the user.
It transforms high-level problem descriptions and constraints into structured information that can be processed by the rest of the framework.

## Scope

The components in this repository are designed to:

- Capture and structure application requirements
- Interpret problem descriptions and objectives
- Derive machine-learning–relevant metadata from user input

## Usage

WP1 module is not intended to operate independently and are integrated into the broader SustainML pipeline.

For installation, configuration, and execution instructions, refer to the main framework repository:

https://github.com/eProsima/SustainML-Framework
